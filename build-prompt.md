# VAPE BARN — WEBSITE BUILD BRIEF

You are building the official ecommerce website for Vape Barn.

This is Phase 1 of the project:
A pre-ecommerce launch website that will later evolve into the full Vape Barn online store.

IMPORTANT:
Read AGENTS.md before doing any implementation.

The visual identity assets provided in the project are authoritative.
Do not redesign the brand identity.
Do not replace the logo, mascot, colours, or established typography with generic alternatives.

The goal is to translate the existing Vape Barn identity into a distinctive web experience.

---

# 1. BRAND IDENTITY

Vape Barn is a South African vape brand/store.

The existing identity is built around:

- a dark navy blue
- warm vape-gold
- warm cream
- subtle tan / wool tones
- the Vape Barn barn logo
- the "Vape Properly" tagline
- the Cloude McPuff sheep mascot

The brand personality is:

- laid-back
- cool
- relaxed
- cheeky
- approachable
- confident
- premium without being pretentious
- slightly playful
- distinctly Vape Barn

Cloude McPuff represents this personality.

He is NOT a cartoon character that needs to appear everywhere.

Use him strategically.

---

# 2. AUTHORITATIVE BRAND ASSETS

Use the existing brand assets in the repository wherever possible.

There are two important reference sheets:

1. Vape Barn logo / brand sheet
2. Cloude McPuff character design sheet

The character sheet establishes:

- character proportions
- colours
- accessories
- expressions
- poses
- visual treatment
- personality

The logo sheet establishes:

- primary logo
- alternate logo arrangements
- barn mark
- typography
- brand colours
- tagline treatment

Treat these as the source of truth.

Do not redraw or reinterpret the logo.

Do not create a new mascot.

Do not alter Cloude McPuff's visual design.

Do not change the brand palette simply because another palette looks more "modern".

---

# 3. CORE VISUAL LANGUAGE

The website should feel like:

Vape Barn.

Not:

- a generic vape store
- a Shopify template
- an AI-generated ecommerce website
- a generic streetwear brand
- a SaaS landing page
- a futuristic technology company
- a cannabis website
- a luxury fashion website

The visual language should combine:

- western/barn character
- editorial ecommerce
- contemporary typography
- tactile materials
- restrained humour
- strong composition
- premium presentation
- subtle imperfections

Think:

"Cool local brand that happens to have an excellent website."

Not:

"Startup that hired an agency to look expensive."

---

Build the interface around the existing brand palette.

Primary visual colours:

NAVY

- cyan

- glowing blue
- excessive black
- generic "dark mode" aesthetics

Cream should play an important role in the site's identity.

---

# 5. TYPOGRAPHY

The existing Vape Barn typography is part of the identity.

Preserve the visual character of the primary condensed bold type.

The brand also uses a script treatment for:

"Vape Properly"

Do not use the script font for large amounts of body copy.

Use it as an accent.

Typography should create most of the visual personality.

Use strong contrast between:

- large condensed display type
- normal readable body text
- small utility text
- occasional script accent

Do not default to Inter everywhere.

If the exact brand fonts are available in the repository, use them.

If they are not available, select the closest appropriate alternatives rather than inventing an unrelated typography system.

---

# 6. CL0UDE MCPUFF

Cloude McPuff is a brand asset, not decoration.

His personality:

- relaxed
- cloud-chasing
- cool
- always unbothered
- enjoys good flavour
- premium but approachable

Use him sparingly.

Good uses:

- hero visual
- launch announcement
- subtle section illustration
- newsletter interaction
- empty states
- playful micro-interactions
- occasional editorial moments

Bad uses:

- putting him beside every heading
- repeating the same image throughout the page
- turning the website into a children's cartoon
- excessive animations
- random mascot stickers everywhere

Cloude should make people smile when they notice him.

He should not overwhelm the brand.

# 7. PHASE 1 — PRE-LAUNCH LANDING PAGE

Build a complete pre-launch landing page.

This should NOT look like a generic "Coming Soon" page.

Do not make:

COMING SOON

the entire concept.

The page should instead feel like the first chapter of the Vape Barn online store.

---

# 8. HEADER

Create a distinctive Vape Barn header.

Include:

- Vape Barn logo
- appropriate navigation
- launch/store indicator
- social/contact where appropriate

Potential navigation:

HOME
SHOP
ABOUT
CONTACT

However, do not create fake destinations.

If SHOP does not exist yet, make its state clearly intentional, such as:

SHOP — COMING SOON

or use another tasteful indication.

Do not make the header feel like a standard ecommerce template.

---

# 9. HERO

The hero is the most important part of the page.

Do NOT use:

centered logo
+
giant heading
+
subheading
+
two buttons
+
gradient background

Instead, create an editorial composition.

The hero should establish:

Vape Barn
+
the upcoming online store
+
the brand personality.

Cloude McPuff can appear here if the composition benefits from him.

Use the actual character asset.

Potential conceptual direction:

A warm cream canvas with navy typography and gold details, with Cloude positioned like a character within an editorial poster / campaign image.

The composition can be asymmetric.

The logo does not need to be huge.

The headline should be short and confident.

Avoid generic copy such as:

"Experience the future."

"Something exciting is coming."

"Your journey starts here."

"Elevate your experience."

Write copy that sounds like Vape Barn.

---

# 10. THE ONLINE STORE ANNOUNCEMENT

Communicate that Vape Barn is moving online.

Make this feel like a brand announcement rather than a technical ecommerce announcement.

Example tone:

"Vape Barn is opening its doors online."

or

"Your favourite Barn is going online."

These are examples only.

Write the final copy based on the actual brand tone.

Keep it confident and slightly playful.

---

# 11. PRODUCT TEASER

Introduce the products people will eventually be able to shop online.

Do NOT build the actual product catalogue yet.

Instead create a teaser.

Use actual product imagery from the project if available.

Potential categories:

- Disposables
- E-liquids
- Devices

# 12. PRODUCT PRESENTATION

Do not use a generic grid of identical rounded cards.

Products can be presented more editorially.

For example:

large product image
+
product name
+
category
+
small supporting information

with varying scale and composition.

Some products can be larger than others.

Use typography and whitespace to create hierarchy.

The eventual ecommerce product cards should evolve naturally from this visual language.

---

# 13. BRAND STATEMENT

Create a strong brand statement section.

This should communicate what Vape Barn stands for.

Keep it short.

Possible themes:

- good flavour
- good products
- proper service
- laid-back attitude
- vaping without unnecessary pretension

Do not make exaggerated health, lifestyle, or performance claims.

Do not write corporate mission-statement nonsense.

The copy should sound like something the people behind Vape Barn would actually say.

---

# 14. CLOUDE MOMENT

Give Cloude McPuff one memorable moment on the page.

This should feel like a small piece of brand storytelling.

Examples of possible approaches:

- Cloude chilling while waiting for the store to launch
- Cloude guarding the Barn
- Cloude sitting beside a launch message
- Cloude interacting with the signup area
- Cloude appearing as an editorial illustration

Do not simply place a PNG in an empty section.

Design the composition around the character.

---

# 15. LAUNCH SIGNUP

Create the primary conversion point.

Purpose:

Allow visitors to register interest in the online store.

Include:

- email address
- clear CTA
- success state
- error state
- validation
- accessible labels

Possible CTA language:

"Keep me posted"

"Let me know"

"Open the Barn"

"Notify me"

Choose the one that best fits the design.

Do not make the signup feel like a SaaS newsletter form.

It should feel like part of the Vape Barn world.

Do not falsely imply that an email was actually saved remotely.

---

# 16. FOOTER

Create a compact, distinctive footer.

Include appropriate:

- Vape Barn logo/mark
- tagline
- social links
- contact
- legal information
- copyright

Keep it simple.

Use the footer as a final brand moment rather than a giant sitemap.

---

# 17. AGE / LEGAL CONSIDERATIONS

Because this is a vape website, the eventual production ecommerce experience will need appropriate age-gating and legal/compliance handling.

For this pre-launch version:

- do not create misleading age claims
- do not make health claims
- do not make claims that vaping is safe
- do not target minors
- do not use childish marketing language
- do not make Cloude's character presentation child-oriented

If an age notice or age gate is required by the actual business/legal requirements, make it easy to introduce without restructuring the application.

Do not invent legal requirements.

---

# 18. RESPONSIVE DESIGN

Desktop and mobile should be deliberately designed.

Do not simply collapse the desktop layout.

On mobile:

- rethink the hero composition
- maintain typography hierarchy
- preserve the cream/navy/gold identity
- carefully crop Cloude imagery
- ensure the signup form works cleanly
- maintain comfortable tap targets
- avoid horizontal scrolling unless intentionally designed

The mobile site should feel like Vape Barn, not a broken desktop site.

---

# 19. MOTION

Keep motion restrained.

Good possibilities:

- subtle logo/element entrance
- gentle image reveal
- hover movement
- small character interaction
- polished form feedback

Do NOT use:

- animated gradients
- excessive parallax
- cursor-following mascot
- constant floating
- excessive bouncing
- text scrambling
- random scroll animations

Motion should reinforce the relaxed personality.

Cloude is laid-back.

The website should be too.

---

# 23. ANTI-AI DESIGN CHECK

After the first implementation, stop and critique it.

Ask:

"Does this look like a website someone deliberately designed for Vape Barn?"

Then ask:

"Could I replace the logo with another logo and sell this as a generic ecommerce template?"

If yes, redesign it.

Ask:

"Does this look like a Shopify theme?"

If yes, redesign it.

Ask:

"Are there too many cards?"

If yes, remove some.

Ask:

"Am I using Cloude because it improves the composition, or because I had an asset available?"

If the latter, remove him.

Ask:

"Am I using gold because it communicates the Vape Barn identity, or because I needed an accent?"

If the latter, reduce it.

Ask:

"Does the page work without gradients and excessive effects?"

It should.

# 25. IMPLEMENTATION PROCESS

Follow this sequence.

1. Inspect the repository.
2. Inspect all existing assets.
3. Identify the current framework and styling system.
4. Identify the logo and Cloude assets.
5. Establish design tokens.
6. Establish typography.
7. Establish the page grid.
8. Create the overall composition.
9. Implement the desktop experience.
10. Implement the mobile experience.
11. Add restrained interactions.
12. Test functionality.
13. Critique the visual result against AGENTS.md.
14. Remove generic or unnecessary elements.
15. Refine the design.
16. Only then consider the task complete.

Do not stop after producing the first technically functional version.

The first version is a design draft.

Refinement is part of the task.
